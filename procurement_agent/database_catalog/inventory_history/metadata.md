# inventory_history 字段元数据

**用途**：`inventory_history` 业务表，查询时必须遵守 `schema.sql` 中的键、约束和关联。

| 字段 | 业务含义与取值规则 |
|---|---|
| `id` | 历史记录主键。 |
| `product_id` | 被消耗产品主键。 |
| `period` | 统计月份；YYYY-MM。 |
| `consumed_qty` | 当期消耗量；非负整数。 |

## 查询约定

- 只读取完成当前业务判断所需字段；关联时使用 `schema.sql` 中声明的主外键。
- 日期按 ISO-8601 文本比较；比率应使用浮点除法并防止分母为零。
- 不推断未列出的固定值；遇到未知值时原样返回并标记待核验。
