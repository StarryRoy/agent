# inventory 字段元数据

**用途**：`inventory` 业务表，查询时必须遵守 `schema.sql` 中的键、约束和关联。

| 字段 | 业务含义与取值规则 |
|---|---|
| `product_id` | 产品主键，一产品一条库存记录。 |
| `current_qty` | 账面现存量；非负整数。 |
| `locked_qty` | 已锁定不可用量；非负整数。 |
| `in_transit_qty` | 已下单未入库量；非负整数。 |
| `safety_stock` | 不可侵占的安全库存；非负整数。 |
| `updated_at` | 库存快照更新时间；ISO-8601 日期/时间文本。 |

## 查询约定

- 只读取完成当前业务判断所需字段；关联时使用 `schema.sql` 中声明的主外键。
- 日期按 ISO-8601 文本比较；比率应使用浮点除法并防止分母为零。
- 不推断未列出的固定值；遇到未知值时原样返回并标记待核验。
