# products 字段元数据

**用途**：`products` 业务表，查询时必须遵守 `schema.sql` 中的键、约束和关联。

| 字段 | 业务含义与取值规则 |
|---|---|
| `id` | 产品内部主键；正整数。 |
| `sku` | 产品唯一编码；按企业物料编码规则取值。 |
| `name` | 产品业务名称；非空文本。 |
| `category` | 产品分类；使用企业分类名称。 |
| `unit` | 计量单位；如“台”。 |
| `quality_standard` | 验收与质保标准；可为空。 |

## 查询约定

- 只读取完成当前业务判断所需字段；关联时使用 `schema.sql` 中声明的主外键。
- 日期按 ISO-8601 文本比较；比率应使用浮点除法并防止分母为零。
- 不推断未列出的固定值；遇到未知值时原样返回并标记待核验。
