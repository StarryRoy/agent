# budgets 字段元数据

**用途**：`budgets` 业务表，查询时必须遵守 `schema.sql` 中的键、约束和关联。

| 字段 | 业务含义与取值规则 |
|---|---|
| `id` | 预算记录主键。 |
| `department_id` | 预算归属部门主键。 |
| `fiscal_year` | 财政年度；四位年份。 |
| `total_amount` | 年度预算总额；非负货币金额。 |
| `used_amount` | 已使用金额；非负货币金额。 |
| `approved_pending_amount` | 已审批待执行占用；非负货币金额。 |

## 查询约定

- 只读取完成当前业务判断所需字段；关联时使用 `schema.sql` 中声明的主外键。
- 日期按 ISO-8601 文本比较；比率应使用浮点除法并防止分母为零。
- 不推断未列出的固定值；遇到未知值时原样返回并标记待核验。
